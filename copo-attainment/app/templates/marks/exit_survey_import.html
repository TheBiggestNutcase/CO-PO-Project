Import from a Google Sheets export

Upload the "Form responses" sheet from your Google Form (in Sheets: File → Download → Microsoft Excel (.xlsx), or Comma Separated Values (.csv)). This will try to match each response to a student on the roster and each column to one of this course's exit-survey questions - you'll get to check and fix all of that on the next screen before anything is saved.

Works best when the sheet has a column with each student's USN and a Timestamp column, which is what Google Forms produces by default. Rating answers can be text ("Excellent", "Good", ...) or already A-E letters - anything not recognized gets flagged for you to fix by hand.
